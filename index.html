What is Horizen?

Horizen is a Discord bot for server protection and management. It includes Antinuke, AutoMod, moderation, music, leveling, logging and 600+ commands.

What is the default prefix?

The default prefix is &. Run &prefixinfo to see your server's prefix and &setprefix to change it.

How do I set Horizen up?

Invite the bot to your server, then run &setup to launch the Master Setup Wizard. Use &systems to review every system.

Does Horizen have a Premium plan?

Yes. Premium gives your server a custom bot identity and priority support. Plans range from 7 days to lifetime.

What permissions does it need?

Place the Horizen role near the top of your role list. The bot can only act on roles below its own.

Are there 18+ commands?

Yes, but they only work in age-restricted channels.

Ready to lock it down?

Add Horizen in a few taps, then run &setup.
